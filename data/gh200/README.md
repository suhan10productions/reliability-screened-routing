# Gehring–Homberger 200-customer instances (R1 and RC1 classes)

Twenty VRPTW instances, R1_2_1 to R1_2_10 and RC1_2_1 to RC1_2_10, from the
benchmark of Gehring and Homberger (1999), in VRPLIB format.

Source: PyVRP instance collection, https://github.com/PyVRP/Instances,
folder `VRPTW/GH200`, commit 7474b068a8effa7f39448b241314b615c9271525
(MIT License, Copyright (c) 2023 PyVRP). Files are unchanged.

Gehring H, Homberger J (1999) A parallel hybrid evolutionary metaheuristic for
the vehicle routing problem with time windows. In: Miettinen K, Mäkelä M,
Toivanen J (eds) Proceedings of EUROGEN99. University of Jyväskylä, pp 57–64.

`code/gh_benchmark.py` maps them to the paper's time-dependent model.
